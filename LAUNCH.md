# Public Build Loop

## Position

Build the missing machine-readable layer of the web. Turn useful human-shaped services and public datasets into APIs that agents can discover and pay for per call.

## Content loop

1. Publish the primitive, exact price, and OpenAPI URL.
2. Show the first real machine payment and returned result.
3. Post a weekly scoreboard: endpoints, unique agents, calls, revenue, failures, and what was killed.
4. Ask agent builders for one blocked task, not generic API ideas.
5. Build the most repeated missing capability and publish the result within 48 hours.

## Channels

- X: short build logs and weekly usage scoreboard
- GitHub: public source, issues titled `primitive request`, and deploy instructions
- MPPscan and mpp.dev: machine discovery
- Hacker News / relevant developer communities: only after a real usage result exists
